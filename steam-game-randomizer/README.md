# 🎮 Game Randomizer

A Progressive Web App (PWA) that imports your Steam library and helps you randomly pick what to play next.

**Features:**
- 🔐 Secure Steam login via OpenID
- 📚 Automatic game library import
- 🎲 Cryptographically secure randomization
- 📱 Install as native Android/Desktop app
- 💾 Offline support with service worker
- 🌐 Works on Windows/Linux/macOS/Android
